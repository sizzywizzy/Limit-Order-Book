    Why the numbers are believable

    Every claim on this page is enforced by a test that runs green, not by an assertion in prose.

    ✓
    1,000,000-op differential

    Naive and fast engines consume identical random flows; their entire event streams compare equal after every single operation.

    ✓
    10,000 × 2 property sequences

    Five invariants — never crossed, conservation, id resolution, aggregate integrity, no ghost levels — checked after every op, on both engines.

    ✓
    Zero allocations, counted

    A replacement global operator new counts every allocation: 0 across 100,000 steady-state operations.

    ✓
    Deterministic replay

    Same input, fresh book, twice: value-identical event streams. It is why this page can replay a run at all.

    ✓
    86 / 86 standalone checks

    Bitmap and id-index fuzzed against reference models; every order type and edge case exercised on both engines.

    ✓
    Hardened rerun

    The full suite repeats clean under _GLIBCXX_DEBUG; CI runs it again under ASan + UBSan on Linux.

    Five structures, no maps

    What replaces std::map, std::unordered_map, and the heap — and why each operation has no search in it.

    O(1) lookupFlat level array

    One contiguous slot per price tick. Finding a level is an add and an index — never a tree walk.

    O(1) best priceTiered bitmap

    One bit per tick, summarised twice. Best bid/ask is three find-first-set instructions; clearing any level costs the same as the best one.

    O(1) unlinkIntrusive FIFO

    prev/next live inside the order as 32-bit slot indices. Cancel is four link writes — the queue is never searched.

    0 allocSlot pool

    Every order pre-allocated at construction, free list threaded through the same next field, pages pre-faulted.

    O(1) id → orderFlat id index

    Open addressing at ≤ 0.5 load, backward-shift deletion: probe runs stay ~1 cache line and never grow with cancel churn.

    Methodology. i7-13700H · g++ 16.2 -std=c++23 -O2 -march=native -DNDEBUG · Windows 11 · timer: unserialised rdtsc calibrated against steady_clock · thread unpinned, frequency scaling active — p50/p99 are stable across runs (spread in the table above); treat p99.99/max as noise ceilings. Workload. Cancel-dominated synthetic flow: ~0.9 cancels per add, 10% of submits aggressive, geometric prices around the touch.
